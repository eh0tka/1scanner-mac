# Security reports

1Scanner opens people's documents, so the most serious bugs are ones that change or lose a file the person didn't
ask to change, leave a password-protected document readable, or let a QR code or PDF open something by itself or
hide where a link really goes.

Please report these privately to **support@onebuckapps.com** with the macOS version, the 1Scanner version and how to
reproduce it (a made-up document is best; never send private documents). You'll get an answer, and the fix ships in
the next release.

For anything else, open a GitHub issue.
